# Contador en Solana

Proyecto de un contador simple hecho en Solana Playground, en Devnet.

## ¿Qué hace?

Es un programa que guarda un número y cada vez que lo llamas le suma +1.

- Cuando se crea la cuenta, el contador empieza en **0**
- Cuando llamas a `greet`, el contador sube a **1**
- Si lo vuelves a llamar, sube a **2**, **3**, etc.

## Tecnologías

- **Solana Playground** - https://beta.solpg.io
- **Rust** - Lenguaje del programa
- **TypeScript** - Lenguaje de las pruebas
- **Devnet** - Red de pruebas de Solana
- **Playground Wallet** - Cartera para desplegar y probar

## Estructura del proyecto
## ¿Cómo se corre?

1.  Abre el proyecto en Solana Playground.
2.  Abajo conéctate a **Playground Wallet** en **Devnet**.
3.  Pícale a **Build** para compilar el programa.
4.  Pícale a **Deploy** para subirlo a Devnet.
5.  Pícale a **Test** para correr las pruebas.
